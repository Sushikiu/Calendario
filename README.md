# Gestor de calendario académico (Java)

> Proyecto orientado a la administración de eventos temporales (exámenes, reuniones y días festivos) aplicando herencia y polimorfismo en Java.

## Conceptos aplicados
* **Programación Orientada a Objetos (POO):** Clases abstractas/herencia (`Evento`, `Examen`, `Reunion`, `DiaFestivo`).
* **Estructuras de Datos:** Manejo de colecciones y arreglos en Java para la organización por meses y días.
* **Control de Flujo:** Menús interactivos con la clase `Scanner` asegurando el manejo seguro de entradas.

## Ejecución
1. Clona el repositorio e importa la carpeta en tu entorno de desarrollo favorito (como Eclipse o IntelliJ).
2. Compila y ejecuta la clase principal: `Main.java`.
